# Game Turbo
Floating window launcher + game booster. Butuh Shizuku.

- Push ke `main` -> GitHub Actions build APK, tes buka di emulator, lalu publish:
  - Release `latest-apk`  : link download APK untuk semua orang
  - Release `data`        : paket data (wallpaper) yang diunduh app saat pertama dibuka
- Isi paket data ada di folder `packs/`.

Repo: https://github.com/Topikkcod/GameTurbo
Download APK: https://github.com/Topikkcod/GameTurbo/releases/latest
